# Hybridized CNN for Mangosteen Ripeness Prediction

This repository contains the Python implementation of a hybrid Convolutional Neural Network (CNN) model for classifying mangosteen fruit ripeness levels from images.

The project was developed as part of an undergraduate final project and focuses on applying deep learning and computer vision techniques to mangosteen ripeness classification.

## Project Objectives

- Classify mangosteen fruit based on its ripeness level.
- Implement a hybrid CNN-based deep learning architecture.
- Train and evaluate the model using mangosteen image datasets.
- Analyze the model's classification performance.

## Technologies

- Python
- TensorFlow/Keras
- Convolutional Neural Network
- Deep Learning
- Computer Vision
- Image Classification
